표본감시 병원의 독감 입원환자가 한 주 만에 639명에서 926명으로 늘었다 — 유행주의보 기간에는 어린이·임신부·65세 이상 같은 고위험군이 의사가 판단하면 검사 없이도 항바이러스제를 건강보험으로 처방받을 수 있고, 국가예방접종 대상 어린이의 접종률은 59.8%다
