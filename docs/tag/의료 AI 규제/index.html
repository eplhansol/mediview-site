의료 AI2026년 10월 28일

미국 전자의무기록이 AI 예측 도구의 학습 데이터·성능 정보를 볼 수 있게 지원할 의무가 사라진다 — 보건복지부가 인증 기준 60개 가운데 14개를 없애는 HTI-5 최종 규칙을 내놓았다

미국 보건복지부(HHS)가 10월 26일 전자의무기록 같은 보건 IT 제품의 인증 기준 60개 가운데 14개를 없애고 7개를 고치는 HTI-5 최종 규칙을 내놓았다. 2025년부터 인증 전자의무기록이 사용자에게 보여 줄 수 있어야 했던 AI·예측형 의사결정지원 도구의 출처 정보 요건도 이번에 빠졌다.
